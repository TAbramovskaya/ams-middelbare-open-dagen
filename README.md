# Amsterdam School Open Days

A Python project that collects open days from [Schoolkeuze020](https://schoolkeuze020.nl/open-dagen/), enriches school data with [AlleCijfers](https://allecijfers.nl/), filters HAVO/VWO schools, and adds their open day events to Google Calendar.

## Features

- Scrapes secondary school open days.
- Enriches data with AlleCijfers links.
- Filters HAVO and VWO schools.
- Imports events into Google Calendar.
